// Overview

项目简介

🤖

多角色 AI 聊天

5 位风格迥异的 AI 角色可供选择，每位角色拥有独立的视觉主题、背景和对话风格。支持流式实时对话，10 秒超时保护。

🎠

3D 角色选择转盘

采用 CSS 3D 透视变换打造的旋转木马式角色选择界面，带有流光边框、光泽扫过动画和动态背景切换。

🔐

隐藏记忆碎片系统

在聊天中输入密码可解锁 8 块"记忆碎片"——每块都是一篇私密的个人随笔，配有音乐、图片和游戏回忆。

🎨

赛博朋克视觉风格

CRT 电视开关机动画、动态极光背景、扫描线叠加、毛玻璃 UI —— 精心打磨的复古未来主义视觉体验。

📱

全设备响应式适配

从桌面端到移动端完整适配，侧边栏滑入式布局，触控手势支持角色转盘滑动切换。

🔗

UID 会话共享

每位用户拥有 8 位随机身份码，可跨设备同步聊天记录，支持"恢复历史"功能找回之前的数据。
